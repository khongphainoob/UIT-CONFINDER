# Đóng góp cho UIT ConFinder

## Luồng làm việc

1. Tạo branch từ `main` mới nhất.
2. Làm một task trong một branch và một PR.
3. Giữ đúng ownership, contract và cấu trúc file.
4. Chạy test phù hợp, cập nhật docs và ghi handoff.
5. Chờ reviewer approve trước khi merge.

## Phân công module

| Thành viên | Phạm vi chính |
|---|---|
| TV1 | Catalog, adapter, deadline, trang chi tiết |
| TV2 | UI foundation, home, about, component demo |
| TV3 | Explore, filter, sort, pagination |
| TV4 | Saved, calendar, hosting và tích hợp |

Mỗi thành viên tự viết phần báo cáo của module mình. TV4 chỉ duy trì khung và
ghép mục lục, không viết thay toàn bộ báo cáo.

## Kiểm tra trước PR

Đọc [docs/task-workflow.md](docs/task-workflow.md) và [docs/testing.md](docs/testing.md).
PR phải ghi task, files đổi, contract, command đã chạy, limitation và handoff.
